# Actualización de marca: Tablero

Este zip trae el proyecto completo con el nombre y el logo nuevos. Al subirlo a GitHub (como las entregas anteriores):

1. Suba/reemplace todo el contenido.
2. **Borre del repositorio** estos archivos, que quedan huérfanos con la marca anterior:
   - public/pitch.js
   - public/assets/fieldpoint-pitch.mp4
   - public/assets/pitch-poster.jpg
   - k6/fieldpoint.js
   - jmeter/fieldpoint.jmx
   - installer/fieldpoint.iss
3. Complete los campos [entre corchetes] de public/privacidad.html y public/terminos.html antes de desplegar.
4. En Vercel renombre el proyecto o conecte un dominio propio (la dirección actual aún contiene el nombre anterior).

No reescriba el historial de commits del repositorio: es la evidencia de autoría.
La base de datos en producción conserva sus usuarios y datos; el esquema se actualiza solo al arrancar.
